# Recipe projects

The projects behind the [recipes](../../docs/recipes/README.md). Each
directory is complete and runnable. Stand-in tools (in `stand-ins/`,
`stand-in/` or `scripts/`) take the place of real third-party CLIs and remote
services, and say so in their comments.

`tests/recipe-examples.test.ts` checks these projects and the recipe pages
against each other.
