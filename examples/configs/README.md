# Config examples

Complete, working projects for common shapes. Each directory has a `.hack/`
setup and a small app. The walkthrough is in
[docs/recipes/config-examples.md](../../docs/recipes/config-examples.md).

Copy a directory, rename `name`, `dev_host` and the `caddy` labels, and
replace the app. `tests/recipe-examples.test.ts` checks these projects and the
doc page against each other.
